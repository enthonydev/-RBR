# RBR — Protótipo de financiamento

Protótipo navegável da interface do RBR, uma ferramenta de planejamento e simulação de financiamento imobiliário.

## Branch

Esta branch contém a interface do RBR em tema escuro. A `main` original foi preservada.

## Fluxo prototipado

- Visão geral do financiamento
- Nova simulação em dois passos
- Resultado comparativo
- Tabela de amortização
- Adição demonstrativa de amortização extraordinária
- Comparação de cenários

Os valores são demonstrativos. O motor financeiro e o backend ainda não estão conectados.

## Execução local

```bash
pnpm install
pnpm dev
```

Verificações:

```bash
pnpm check
pnpm build
```
